## Description
This repository contains the following files for the assignment:  

- `stats.c` → implementation of statistical functions (min, max, mean, median, sorting)  
- `stats.h` → function prototypes and documentation  
- `README.md` → this file  

The program reads an array of unsigned char values, prints the original array, calculates and prints statistical metrics, and prints the array sorted from largest to smallest.
